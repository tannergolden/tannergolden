## 💡 About Me

I'm a software engineer building infrastructure for AI research. My focus is
the layer under the experiments: environments that rebuild the same way every
time, dependencies that are pinned and scanned, and CI that fails for the
right reasons, so a result can be trusted and repeated.

Most of my public work is one connected system.
[`standards`](https://github.com/tannergolden/standards) holds the engineering
rules and the reusable workflows that enforce them, called by link so a fix
lands once and reaches every repository.
[`path`](https://github.com/tannergolden/path) is the template new
repositories start from, and
[`markdown`](https://github.com/tannergolden/markdown) draws READMEs like this
one from data measured on a schedule.

- **Working on:** reproducible environments, supply-chain hygiene (pinned
  dependencies, secret scanning, CodeQL and SBOMs), and CI that fails for the
  right reasons.
- **Building with:** Python (standard library first), GitHub Actions, Bash and
  Make, plus dev containers and Codespaces so a Mac and a fresh container start
  from the same shell.
- **How I work:** standards a machine enforces, small reviewable changes,
  Conventional Commits, and signed commits on protected branches.
- **Ask me about:** reusable workflows, dependency pinning, release automation,
  and automating the chores nobody should do by hand.

## 💡 How It Fits Together

Follow the arrows from the rules to this page.
[`standards`](https://github.com/tannergolden/standards) holds the rules and
the reusable workflows that enforce them, called by link and never copied, so
a fix lands once and reaches every repository pinned to it.
[`path`](https://github.com/tannergolden/path) is the template every new
repository starts from, already wired to those workflows. A repository that
wants a drawn README adds one
[`markdown`](https://github.com/tannergolden/markdown) stub. Once a day the kit
it calls measures the repository, or here the account, redraws what moved and
commits it as SVGs, header to footer in one commit, so nothing on this page
depends on a third-party service.

## 📝 Field Notes

<!-- notes:start -->

> [!NOTE]
> **Professional · HTTP.** TLS 1.3 early data lets a returning client send its first request without waiting for the handshake, but an attacker can replay that data, so servers should accept only idempotent requests in it and can answer others with `425 Too Early`.

> [!TIP]
> **Beginner · Shell.** Insert a command's output into another command with `$(...)`, as in `echo "Backup from $(date +%F)"` or `cd "$(git rev-parse --show-toplevel)"` to reach the repository root.

> [!IMPORTANT]
> **End of life · [Ruby 3.3](https://endoflife.date/ruby).** Ruby 3.3 stops getting security fixes on 31 March 2027. Move to 4.0, the newest release.

> [!WARNING]
> **Advanced · Algorithms.** A Bloom filter's false-positive rate climbs steeply once it holds more items than it was sized for, and entries cannot be removed. Size it for the maximum item count and target rate, and rebuild it when you outgrow that.

> [!CAUTION]
> **Professional · Incidents.** Rehearse failing over to your disaster recovery region, and failing back, on a schedule. A first attempt made during a real disaster often stalls on a dependency nobody remembered.
