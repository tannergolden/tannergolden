# 📡 DISPATCHES

<a name="top"></a>

**One file per month, one dispatch per commit, nothing above a dispatch ever rewritten.**

_The archive the page is cut from._

</div>

---

Each month is a file at `dispatches/<year>/<Month>.md`, created on the first dispatch of that month
and appended to until the next month begins. Every dispatch carries its Eastern Time timestamp, its
commit type, the text, and its source and license. The page shows the newest; this is the rest.

How dispatches are chosen, timed and attributed is in [How it works](../How-It-Works.md).
