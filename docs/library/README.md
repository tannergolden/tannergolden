## 💡 What This Folder Is For

Learning material for anyone new to this project's domain or its tools: here,
how to play the four games on the profile. [Games](Games.md) has what all four
share, and each game's own guide has its rules, how its moves are written and
how its games end.

- **Guides**: how to do something with the project, step by step.
- **Background**: the ideas and the domain a contributor needs, explained once.
- **Further reading**: the sources worth keeping, each with a line on why.
